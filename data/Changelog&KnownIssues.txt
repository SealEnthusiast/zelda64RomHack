-How to Migrate model-

- In your original model, delete all but riggedmesh (Link model) and the desired items
- Delete the rigged mesh from new file and paste new one
- In Text Editor run the following scripts in order:
	- MigrateMatsToObjex2.6
	- RenameShoulderBones (if adult link)
	- ArmatureSetOnAllObjects
- Locate the eyes and mouth materials of your model, and change the material to the Eyes and Mouth materials that already existed in the new file then replace the textures as needed. This is very important for preview purposes.
- If some parts of the model look black&white, convert the textures from tga to png yourself and reload them.
